# Задание 1

## Задача 12

### Текст задачи

В задании 1 реализовать определение класса (поля, конструкторы (не менее трех), перегрузку оператора вывода для вывода полей, заданный метод согласно варианту). Протестировать все методы, включая конструкторы.

Вариант 12.

Название класса: Time

Поля:

- short int hours
- short int minutes

Метод: вычитание минут (unsigned int) из объекта типа Time (учесть, что возможен переход в какие-либо предыдущие сутки). Результат должен быть типа Time.

### Алгоритм решения

Для решения задачи создан класс `Time` с двумя полями типа `short int`: `hours` (часы) и `minutes` (минуты). Значение времени всегда хранится в пределах одних суток: часы от 0 до 23, минуты от 0 до 59.

В классе реализованы три конструктора:

- конструктор по умолчанию, который устанавливает время 00:00;
- конструктор с параметрами (часы и минуты), который приводит переданные значения к корректному суточному времени: часы берутся по модулю 24, минуты по модулю количества минут в сутках (1440), затем время переводится в количество минут с начала суток, при необходимости (если значение получилось отрицательным) к нему прибавляются сутки, после чего количество минут делится на 60 для получения часов, а остаток от деления становится минутами;
- конструктор копирования, который переписывает значения полей из другого объекта `Time`.

Метод вычитания минут реализован в виде перегруженного бинарного оператора `-`, правым операндом которого является беззнаковое целое число (количество вычитаемых минут). Метод не изменяет исходный объект и возвращает новый объект `Time`. Порядок вычисления следующий:

1. Текущее время переводится в количество минут с начала суток (часы умножаются на 60 и складываются с минутами).
2. Количество вычитаемых минут заменяется остатком от деления на 1440, так как вычитание целого числа суток не меняет время суток.
3. Из текущего количества минут вычитается полученное значение.
4. Если результат оказался отрицательным, к нему прибавляется 1440 минут, что соответствует переходу в предыдущие сутки.
5. Итоговое количество минут переводится обратно в часы и минуты, и по ним создаётся новый объект `Time`.

Для вывода значений полей перегружен оператор вывода `<<`. Он является дружественной функцией класса и выводит время в формате «ЧЧ:ММ», при этом часы и минуты дополняются ведущим нулём до двух знаков. Для доступа к значениям полей добавлены методы `GetHours()` и `GetMinutes()`.

В главной функции создаётся объект `Time`, и в меню показывается работа всех конструкторов и метода вычитания минут.

# Задание 2

## Задача 12

### Текст задачи

В задании 2 добавить к реализованному в первом задании классу указанные в варианте перегруженные операции.

Вариант 12.

Название класса: Time

Унарные операции:

- `-` — обнуление часов и минут в объекте типа Time.
- `--` — обнуление минут в объекте типа Time.

Операции приведения типа:

- short int (неявная) — результатом является количество часов (минуты отбрасываются);
- bool (явная) — результатом является true, если часы и минуты не равны нулю, и false в противном случае.

Бинарные операции:

- `==` Time t — результатом является true, если значение часов и минут левого операнда равно соответствующим значениям правого операнда, и false в противном случае.
- `!=` Time t — результатом является true, если значение часов и минут левого операнда не равно соответствующим значениям правого операнда, и false в противном случае.

### Алгоритм решения

В класс `Time` из задания 1 добавлены следующие перегруженные операции.

Унарные операции:

- Унарный оператор `-` обнуляет оба поля объекта: и часы, и минуты. Изменение выполняется над самим объектом, оператор возвращает ссылку на него.
- Префиксный оператор `--` обнуляет только поле минут, часы остаются прежними. Оператор также изменяет сам объект и возвращает ссылку на него.

Операции приведения типа:

- Неявное приведение к `short int` возвращает значение поля часов; минуты при этом отбрасываются. Так как оператор неявный, объект `Time` можно использовать там, где ожидается значение типа `short int`.
- Явное приведение к `bool` возвращает true, если хотя бы одно из полей (часы или минуты) не равно нулю, и false, если оба поля равны нулю. Оператор объявлен как `explicit`, поэтому преобразование к `bool` выполняется только при явном указании типа.

Бинарные операции:

- Оператор `==` сравнивает объекты по значениям полей: возвращает true, если часы левого операнда равны часам правого и минуты левого операнда равны минутам правого, иначе возвращает false.
- Оператор `!=` реализован через оператор `==`: он возвращает отрицание результата сравнения на равенство.

В главной функции в меню добавлены пункты, демонстрирующие работу каждой из перечисленных операций: обнуление часов и минут оператором `-`, обнуление минут оператором `--`, приведение времени к `short int` и к `bool`, а также сравнение двух объектов `Time` операторами `==` и `!=`.
